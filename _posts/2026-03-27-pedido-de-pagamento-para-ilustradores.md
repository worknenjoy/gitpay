## O que é um pedido de pagamento (para Ilustradores)

Um pedido de pagamento é um link simples que você envia após a entrega para que o cliente pague imediatamente — sem anexar PDFs, cobrar assinaturas ou esperar um fluxo contábil.

## O ciclo comum de atraso no pagamento

- Entregar o trabalho
- Enviar fatura
- Esperar
- Cobrar

## Um fluxo mais rápido com um link de pedido de pagamento

1. Entregue o marco
2. Envie um único link de pedido de pagamento, claro
3. O cliente repassa internamente se precisar
4. O pagamento acontece mais rápido porque a ação é óbvia

## Exemplos de uso para Ilustradores

- Conjunto de ilustrações personalizadas
- Entrega de pacote de ícones
- Ilustrações editoriais
- Design de mascote

## Por que pedidos de pagamento funcionam melhor que faturas

- Um link é mais fácil de aprovar e pagar
- Menos atrito para entregáveis pequenos e médios
- Funciona bem com clientes internacionais
