Como contribuidor, você resolve issues que têm recompensa. Você recebe quando seu pull request é mesclado e a issue é fechada.

## 1. Cadastre-se com o GitHub

Cadastre-se ou entre em [gitpay.me](https://gitpay.me) **com o GitHub**. O Gitpay usa sua conta do GitHub para confirmar que você é o autor do pull request enviado, então uma recompensa só pode ser paga a uma conta que entrou com o GitHub.

Depois, adicione o papel **Contributor** em **Conta → Perfil** (seção "Que tipo de usuário é você?"). Você também pode adicionar suas habilidades em **Conta → Habilidades**.

## 2. Configure seus saques

Configure sua conta de saque Whop antes de terminar sua primeira solução, para a recompensa poder ser transferida assim que for aceita. Veja [Configure seus saques](/docs/br/whop-payout-setup/).

## 3. Encontre uma issue

Vá em **Tarefas → Explorar incidentes**. Cada issue mostra a recompensa, o estado e o prazo, se o dono definiu um.

| Estado | Significado |
|---|---|
| **Created** (criada) | Ainda sem recompensa. Você pode resolver mesmo assim e pedir pagamento ao mantenedor. |
| **Funded** (financiada) | Há dinheiro guardado para quem resolver. |
| **Claimed** (reivindicada) | A solução de um contribuidor foi aceita e a transferência da recompensa começou. |
| **Completed** (concluída) | A recompensa foi transferida ao contribuidor. |
| **Closed** (fechada) | Fechada no Gitpay, por exemplo depois de a recompensa ser reembolsada. |

Uma recompensa marcada como **A pagar mais tarde** é um compromisso: o patrocinador paga quando uma solução é aceita, não antes.

## 4. Trabalhe nela

Leia a issue no GitHub e avise o dono que você está trabalhando nela. Veja [Trabalhe em uma issue financiada](/docs/br/contributor/).

## 5. Envie sua solução e receba

Abra um pull request no mesmo repositório, citando a issue. Quando ele for mesclado e a issue fechada, envie a URL do pull request ao Gitpay. Se tudo estiver certo, a recompensa é transferida para a sua conta de saque. Veja [Envie uma solução](/docs/br/pull-requests/).
