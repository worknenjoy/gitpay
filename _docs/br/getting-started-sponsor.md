Um patrocinador financia issues. Você pode financiar uma issue do seu próprio projeto, ou qualquer issue de código aberto que queira ver resolvida. Você só paga por uma solução que for mesclada: se ninguém resolver, uma recompensa paga antecipadamente pode ser reembolsada, e um compromisso de pagar depois nunca é cobrado.

## 1. Crie uma conta

Cadastre-se em [gitpay.me](https://gitpay.me) com e-mail, GitHub ou Bitbucket, e adicione o papel **Funding** em **Conta → Perfil** (seção "Que tipo de usuário é você?").

Você não precisa de conta de saque para financiar issues. Ela só é necessária para receber dinheiro.

## 2. Encontre ou importe a issue

- Se a issue já está no Gitpay, encontre em **Tarefas → Explorar incidentes**.
- Se não está, selecione **Importação → Importar tarefa** na barra superior e cole a URL da issue do GitHub ou do Bitbucket. Veja [Importe issues e projetos](/docs/br/getting-started-maintainer/).

## 3. Adicione uma recompensa

Na issue, selecione **Adicionar recompensa**, informe o valor e escolha como pagar: cartão, fatura ou carteira, agora ou depois. A taxa é somada ao valor e aparece no total com taxa antes de você confirmar. Veja [Financie uma issue](/docs/br/sponsor/).

## 4. Acompanhe o trabalho

Suas issues financiadas ficam em **Tarefas → Meus incidentes → Patrocínio**. Seus pagamentos, faturas e status ficam em **Pagamentos → Pagamentos**.

Quando o pull request de um contribuidor é mesclado e a issue é fechada, o contribuidor envia a solução e o Gitpay paga. Você não precisa aprovar a transferência.
