You don't need permission to solve an issue on Gitpay. The bounty goes to whoever authored the merged pull request that solves it. Still, telling the owner you're working on it avoids two people solving the same issue, and lets you agree on a date or a bounty first.

## Read the issue page

The issue page on Gitpay shows:

- **Bounty**: the total, with a breakdown per sponsor. Amounts are marked **Paid in advance** (held by Gitpay), **Invoice pending** or **To pay later** (pledged; the sponsor pays when a solution is accepted).
- **State**: Created (no bounty), Funded, Claimed, Completed or Closed.
- **Deadline**: the date the owner needs a solution by, if set.
- **Solutions sent**: pull requests other contributors already submitted.
- **Visibility**: public issues appear in Explore; *not listed* issues can only be opened with the link.

Check **Solutions sent** before you start, so you don't duplicate someone else's work.

## Apply to work on it

On the issue, apply to solve it. You can:

- describe your plan in a short message;
- suggest a delivery date.

The owner reviews applications and can assign the issue to you. You'll see it under **Issues → My issues → Issues I'm working on**.

## Make an offer

Use **Make an offer** to propose a bounty, for example when the issue has no bounty yet or when you think the scope is bigger than the current bounty. Your offer includes a value and a suggested deadline. If the owner accepts it, Gitpay creates an order for that amount (with the 8% open source fee) for the owner to pay. You're paid when your solution is merged.

## Talk to the owner

Use **Message** on the issue page to contact the person who imported the issue. Keep technical discussion on the GitHub issue, where the maintainers will see it.

## Invite others

Use **Share with others** to:

- **Invite contributor**: ask a developer to work on the issue;
- **Invite sponsor**: ask someone to add to the bounty;
- **Post on GitHub**: comment on the GitHub issue with a link to the Gitpay page.

## When you're done

Open a pull request and submit it as your solution: [Submit a solution](/docs/en/pull-requests/).
